# DRI Signal Construction and Baseline Portfolio Performance

Implementation of the **Daily Return Information (DRI)** cross-sectional equity
return predictor.  The signal is built from 42-dimensional feature vectors
combining 21 chronologically-ordered and 21 rank-ordered demeaned daily returns,
estimated via elastic-net regression in an expanding-window out-of-sample framework.

## Methodology Summary

### Feature Construction (Phase B)
For each eligible stock-month pair:
1. Retrieve the 21 most recent trading-day returns ending on the month's last day.
2. **Cross-sectionally demean** each calendar date's returns across the eligible universe.
3. Chronological vector **R^C** = demeaned returns, most-recent first (d=1 … 21).
4. Rank vector **R^R** = same 21 values sorted descending (k=1 = maximum).
5. Feature vector: **R_{i,t} = [R^C_{i,t} ‖ R^R_{i,t}]** (42-dim).
6. Response: next-month excess return y_{i,t+1}.

### Elastic-Net (Phase C)
```
L = (1/N) Σ (y − α − Xβ)² + λ [(1−η)‖β‖₂² + η‖β‖₁],  η = 0.5
```
- **Expanding window**: training on all months up to December of year Y.
- **Lambda selection**: 5-fold CV × 5 repeats (25 evaluations), log-spaced grid of 100 λ values.
- **Parallelised** via `n_jobs=-1` (all CPUs).
- Coefficients updated once per year; the same β is applied to all 12 months of year Y+1.

### DRI Signal (Phase D)
```
DRI_{i,t} = (R^C_{i,t})' β^C_Y  +  (R^R_{i,t})' β^R_Y
```

### Portfolio Formation (Phase E)
- Sort eligible stocks into 10 deciles on DRI each month.
- Compute value-weighted (VW) and equal-weighted (EW) portfolio returns.
- Report mean return, Newey-West t-stat (12 lags), annualised Sharpe ratio, and
  six-factor (FF6) alpha with Newey-West standard errors.

## Quick Start

```bash
pip install -r requirements.txt

# Run Experiment 1 (DRI signal & decile portfolios)
python -m exp.exp1_dri_signal

# Run Experiment 2 (component decomposition & spanning tests)
python -m exp.exp2_component_decomposition

# Run all tests
python -m pytest tests/ -v
```

### Using Real CRSP Data
Set `MASSIVE_TOKEN` and call `data.data_loader.load_crsp_monthly` /
`load_crsp_daily` with your WRDS credentials.  The synthetic fallback is used
automatically when `MASSIVE_TOKEN` is absent or the API returns no data.

## Key Results (Synthetic Proxy, 200 stocks, 1985-2005)

| Signal   | VW H-L Mean% | t-stat | SR   | FF6 α% | t(α)  |
|----------|------------:|-------:|-----:|-------:|------:|
| DRI (42) |       1.860 |   6.53 | 1.73 |  2.349 |  5.39 |
| Chron    |       1.860 |   6.53 | 1.73 |  2.349 |  5.39 |
| Rank     |      −0.387 |  −1.42 |−0.39 | −0.513 | −1.65 |

- **beta_C[d=1] = −0.29** (negative ✓ — short-term reversal dominates)
- **100 %** of years: ‖β^C‖₁ > ‖β^R‖₁ (chronological component dominates)
- Full CRSP universe targets: VW H-L ~1.57 %, t~10.94, SR~1.23

## Configuration

Both experiment scripts expose a `CFG` dict at the top.  Key settings:

| Parameter         | Default    | Description                              |
|-------------------|-----------|------------------------------------------|
| `n_stocks`        | 200       | Synthetic universe size                  |
| `start`           | 1985-01-01| Data start                               |
| `end`             | 2005-12-31| Data end                                 |
| `train_end_year`  | 1994      | Last year of expanding-window training   |
| `test_start_year` | 1995      | First year of out-of-sample test period  |
| `n_splits`        | 5         | CV folds                                 |
| `n_repeats`       | 5         | CV repetitions (25 total)                |
| `run_augmented`   | False     | Enable 462-feature interaction model     |
