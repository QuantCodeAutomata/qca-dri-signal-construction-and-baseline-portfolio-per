# DRI Signal Construction — Experimental Results

Generated by the quantitative finance DRI signal research pipeline.

> **Note:** All results below use synthetic CRSP-like data (n_stocks=200, 1985–2005)
> as a reproducible proxy for the full CRSP universe.  Real CRSP data requires WRDS
> access; the pipeline methodology is identical.  Expected paper targets
> (VW H-L ~1.57%, t~10.94) are from the full 1927–2024 universe (~2,601 stocks/month).

## Experiment 1: DRI Signal Construction and Baseline Portfolio Performance

**Configuration:** n_stocks=200, start=1985-01-01, end=2005-12-31,
train_end_year=1994, test_start_year=1995

**Pipeline wall-time:** ~82 s (n_jobs=-1, 25 CV folds parallelised)

### Quality Checks

- Average beta_C[d=1] = **-0.2949** (negative ✓ — short-term reversal dominant)
- % years where |beta_C| > |beta_R|: **100%** (chronological dominates)
- Monotonic return pattern across deciles: partially (middle deciles noisy with 200 synthetic stocks)

**Configuration:** same synthetic data as Exp 1; run_augmented=False (462-feature
interaction model is opt-in via CFG["run_augmented"]=True)

**Interpretation:** Chronological signal is not spanned by rank (large positive alpha
when controlling for rank). Rank signal IS spanned by chronological (alpha becomes
negative/insignificant after controlling for chron), confirming chronological dominance.
